## Lab Activity Instance 

## Lab Activity 1
- **Lab 1 Theme (Dark/Light Mode)**: Sa activity na ito, natutunan ko ang difference ng Ephemeral State at App State sa Flutter. Ang Ephemeral State ay ginagamit para sa temporary data tulad ng counter gamit ang setState(), habang ang App State ay para sa data na kailangang ma-share sa iba't ibang screens gamit ang Provider. Natutunan ko rin kung paano mag-manage ng app theme (Light at Dark Mode) at kung paano mag-update ng UI kapag nagbago ang state. Overall, mas naintindihan ko kung kailan gagamit ng setState() at kung kailan mas appropriate ang Provider para sa state management.

## Lab Activity 2 
- **Lab 2 API**: Sa activity na ito, natutunan ko kung paano gumawa at gumamit ng API sa Flutter para kumuha at mag-display ng data mula sa isang external source. Natutunan ko rin kung paano paghiwalayin ang Model, Service, at Screen para mas organized at madaling i-maintain ang code. Mas naintindihan ko kung paano gumagana ang API requests, pagkuha ng JSON data, at pag-convert nito sa Dart objects gamit ang model. Natutunan ko rin kung paano mag-handle ng loading at error states habang kinukuha ang data. Overall, mas naintindihan ko kung paano kumonekta ang Flutter application sa API at kung paano gumawa ng mas maayos at structured na application gamit ang proper code organization.

## Lab Activity 3
- **Lab 3 API Part II**: Sa activity na ito, natutunan ko kung paano mag-integrate ng Cart API sa Flutter gamit ang Provider pattern. Gumawa rin ako ng cart.dart at cart_service.dart para mas maayos ang organization ng code at API data.

## Lab Activity 4
- **Lab 4 API Part III**: The original activity used DummyJSON for sample sign-in and cart data. The Firebase Authentication Lab section below replaces sample authentication with Firebase Email/Password and Firestore profile storage.

## Lab Activity 5
- **Lab 5 Firebase**: Sa activity na ito, in-integrate ko ang Firebase Email/Password Authentication gamit ang Provider para ma-manage ang user at session state ng buong app, at ang Cloud Firestore para sa profile data. Puwedeng mag-register at mag-sign in ang mga user, mag-reset o mag-update ng password, magpalit ng username, mag-delete ng account, at mag-log out na may confirmation prompt. Inihambing ko rin ang managed authentication at automatic token refresh ng Firebase sa sample API login ng DummyJSON. Sa profile screen, ipinapakita ang account type at mga detalye ng user.
